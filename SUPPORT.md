# Getting help

Roamkeep is made by one person. Help is given in public where possible, so
the next family with the same question finds the answer.

| If you want to… | Go to |
|---|---|
| Set up your family, or join one | [roamkeep.app/get-started](https://roamkeep.app/get-started/), then [docs/OWNER_SETUP.md](docs/OWNER_SETUP.md) |
| Find a quick answer | [roamkeep.app/faq](https://roamkeep.app/faq/) |
| Ask a question | [Discussions](https://github.com/roamkeep/roamkeep/discussions) |
| Report a bug | [a new issue](https://github.com/roamkeep/roamkeep/issues/new/choose), using the bug form |
| Report a security problem | [private reporting](https://github.com/roamkeep/roamkeep/security/advisories/new), never an issue (see [SECURITY.md](SECURITY.md)) |
| Delete your account | [roamkeep.app/delete-account](https://roamkeep.app/delete-account/) |
| Anything private | [support@roamkeep.app](mailto:support@roamkeep.app) |

**What we can't do:** see, recover or delete your family's data. It lives in
your family's own Supabase project, which only your family can reach.
Forgotten your password? An owner of your Keep can give you a reset code from
the app. An owner recovers their own through the Supabase account that holds
the server: on the sign-in screen, **Forgot password?** → **I'm an owner of
this Keep**.

**Never post** a setup or invite link, a Supabase access token, or anyone's
location. If you already have, delete the token in Supabase and rotate your
invite code in the app.

This is a small project, so replies can take a few days. A clear report,
with the app version and phone, gets the fastest answer.
