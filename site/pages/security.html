Security

Your family's data, reachable only by your family

That is Roamkeep's whole premise. This is how it holds, how to tell us if it doesn't, and how to check the app you installed.

How it's protected

  • A database per family. Each family's locations live in its own Supabase project. Nothing is shared between families, and nothing passes through us.
  • Row-level security. The database itself decides who can read and write each row, so a modified app gets no further than the real one. The key inside a setup link is public by design; the security rules are the boundary.
  • Rules the server enforces. Owner approval of new members, what children can and can't do, and who may change sign-ups are checked by the database, not by the app.
  • Notifications without content. The relay that wakes phones sends an empty message and keeps no record of it.
  • Encrypted in transit. Every connection between the app and your database uses HTTPS.
  • Open to inspection. The source is public. The app is minified to make it smaller, not to hide anything.

Report a vulnerability

Please don't open a public issue. Use GitHub's private vulnerability reporting, or email security@roamkeep.app. Tell us what an attacker could do, how to reproduce it, and which version you tested. Never include another person's real location data.

Check the app you installed

The app on Google Play is built from the public source. From Roamkeep 4.11.0, each release on GitHub lists the SHA-256 of the app's main script, app.js, which is identical in every copy. To compare yours, with a computer and adb:

  1. Find the app: adb shell pm path com.roamkeep.app
  2. Copy it off the phone: adb pull <the path it printed> roamkeep.apk
  3. Take the script out of it: it is assets/public/app.js inside the APK, which is a zip file.
  4. Hash it (sha256sum app.js, or Get-FileHash app.js on Windows) and compare with the release.

Google re-signs apps it distributes, so the APK's own signature differs from a build you make yourself. The script inside it does not.
